Lane County Hot Jobs

A pilot job list for Lane County, refreshed nightly from the Oregon Employment Department's QualityInfo Job Finder. Any partner website can show it with one line of code.

Add it to your website

  1. In WordPress, edit the page and add a Custom HTML block.
  2. Paste this one line: 
    <script src="WIDGET_URL" defer></script>
  3. Preview, then publish. The list updates by itself every night.

To start the list on one type of work, add a setting, for example data-type="Healthcare & human services". Other settings: data-industry, data-city, data-title.
