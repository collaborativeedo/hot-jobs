Data: Oregon Employment Department QualityInfo Job Finder and WorkSource Oregon listings, plus employers' own hiring systems, collected nightly by Collaborative Economic Development Oregon for Lane Workforce Partnership. Sector ("type of work") comes from each posting's federal occupation code where available, otherwise from the job title. Counts are of postings, not positions; one posting can cover several hires, and not every opening is posted online. Large jumps on a single day usually reflect a change in what the run reads (a new source or better employer naming), not a change in hiring. This page is not linked from the job seeker widget.
